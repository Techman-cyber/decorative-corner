Google/Apple sign-in not working?
  • Open this site over http:// or https:// (e.g. a local dev server) — not by double-clicking the HTML file, since Google/Apple pop-ups refuse to run from a file:// page.
  • In the Firebase console, confirm Google (and Apple) are turned on under Authentication → Sign-in method.
  • Add whatever domain you're testing on (e.g. localhost, or your real domain) under Authentication → Settings → Authorized domains.
  • Double-check firebase-config.js has your actual project values, not the placeholder text.
  • Open the browser console (F12) — the exact error code shows there and above the form.
